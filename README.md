# 你的武侠灵魂 · Your Wuxia Soul

🎮 一个趣味向的门派人格测试网页，5道题测出你是《燕云十六声》里的哪一脉。
A fun personality test to find which sect from *Where Winds Meet* matches your soul.

## 预览 / Preview

👉 **在线体验 / Live Demo:** https://wangxinyi1014.github.io/your-wuxia-soul/

## 特色 / Features

- 🏮 古风武侠视觉，宣纸质感 + 朱砂配色 / Ancient Chinese wuxia aesthetic with rice paper texture
- 🌐 中英双语切换 / Bilingual (Chinese / English)
- 📱 移动端优先，手机上玩最舒服 / Mobile-first design
- ⚡ 纯前端单页，加载快，无依赖 / Single-file, zero dependencies
- 🎯 12大门派全覆盖 / All 12 sects included

## 本地运行 / Local Run

直接用浏览器打开 `index.html` 即可。
Simply open `index.html` in any browser.
